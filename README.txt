Attendance Trackie — Reimagined build

Import index.html into your HTML-to-APK builder. Character PNGs are included separately for reference; they are embedded in index.html so no external file path is required.

Bunk calculator: the maximum is calculated from remaining scheduled periods/classes for the selected subject up to its subject/semester end date. When weekly timetable periods exist for a subject, each unmarked period is counted separately. Otherwise the subject teaching-day schedule is used. Holidays/marked dates are not counted as future absences.

Attendance scoring functions were preserved. Validate in your target APK builder before relying on background notifications or storage bridges.
